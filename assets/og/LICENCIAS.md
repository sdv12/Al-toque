# Fuentes para las imágenes de vista previa (Open Graph)

Copias en TTF de las tipografías de cada plantilla, usadas solo al generar las imágenes
`/l/<slug>/opengraph-image` en el build (no se envían al navegador). Todas son de Google Fonts
bajo la SIL Open Font License 1.1, que permite redistribuirlas junto al software:

| barberia-cuerpo.ttf | Jost | 400 |
| consultorio-display.ttf / -cuerpo.ttf | Atkinson Hyperlegible Next | 700 / 400 |
| alojamiento-display.ttf | Fraunces | 600 |
| alojamiento-cuerpo.ttf | Literata | 400 |
| generico-display.ttf | Bricolage Grotesque | 800 |
